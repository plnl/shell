# 变更日志

## v1.0

**从 `ipblock` v2.10 的「菜单 10」抽成独立脚本**

抽出后与 ipblock 内的实现保持同一套逻辑，额外补了三处：

- `--status`：只读打印当前登录方式，可直接给脚本 / 监控用（非交互，不需要终端）
- `--backup`：命令行备份一次 sshd 配置
- 操作日志 `/var/log/sshmenu.log`（超 2MB 自动截断），记录每次切换、加删密钥

功能：查看登录方式 / 安装密钥（粘贴·导入·生成）/ 切换 仅密钥·仅密码·密钥+密码 / root 策略 / 查看删除已授权密钥 / 改端口 / 查看登录记录 / 配置备份回滚。

安全机制（与 ipblock 一致）：

- 判断当前状态只认 `sshd -T`，不读配置文件
- 改动顺序：备份 → 注释所有冲突行（含 `Include` 的 `sshd_config.d/*.conf`）→ 写托管块 → `sshd -t` → 重载/重启 → `sshd -T` 核对生效值 → 不一致回滚
- 备份用 `cp` + manifest 存到 `/etc/ssh/ipblock-backup/<时间戳>/`，保留 10 份（与 ipblock 共用该目录，时间戳隔离）
- 切「仅密钥」前检查是否已有授权密钥，没有直接拒绝
